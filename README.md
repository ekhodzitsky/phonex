# siamstt

> On-device Thai speech-to-text server. Local inference, no cloud APIs, full privacy.

## Overview

`siamstt` is a single-binary Rust server that turns any machine into a real-time Thai speech-to-text endpoint. Inspired by [gigastt](https://github.com/ekhodzitsky/gigastt).
